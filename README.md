# Regulix

Regulix is a React dashboard for compliance management, audits, and compliance workflows.

## Development

Install dependencies and start the local development server:

```sh
npm ci
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Deployment

Pushing to `main` builds and deploys the site to [GitHub Pages](https://tanuja0918.github.io/regulix/) using GitHub Actions. In the repository settings, set **Pages ? Build and deployment ? Source** to **GitHub Actions**.
